Read the matching skill below. For a series review, start with $ig-audit, then use $ig-plan for scheduling and $ig-reel for the pilot. Respect the approved characters, duration and sound direction. Separate observations from performance hypotheses. Use the user’s language.

Run examples from the Poster repository root. Optional local notes go in `storage/app/private/instagram/`; create that directory when saving requested notes. Use [the voice template](templates/voice.md) when setting up an editorial voice.
