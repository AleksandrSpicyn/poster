# Задание для Dot — Direct Post

Используй эту инструкцию после выкладки версии с беспарольным кабинетом. Проверь в существующем TikTok-приложении Sandbox, target users, Web Login Kit, Display API, Content Posting API и включение Direct Post. Точный callback — HTTPS-адрес стенда с путём `/demo/tiktok/callback`. Требуются права `user.info.basic`, `video.list`, `video.publish`, `video.upload`. Кабинет открывается по `/demo/tiktok/authors`.

Оставь `TIKTOK_DEMO_MODE=sandbox` и `TIKTOK_DEMO_UPLOAD=false`. Ключи Sandbox передай через приватную конфигурацию стенда. Пароли демо-авторов больше не нужны. Передай владельцу ввод данных TikTok, MFA и согласие. Проверь профиль и пустое состояние списка либо реальные метрики. Для второго автора используй отдельный браузер. По [сценарию записи](tiktok-demo.md) продемонстрируй выбор собственного файла, предпросмотр, ограничения видимости, маркировки и согласие. Для реальной отправки потребуется отдельное поручение владельца.

Верни отчёт о проверенных шагах и доступности `video.publish`. До одобрения и аудита сохраняй Sandbox. Не отправляй заявку на модерацию, не выдавай тестовую демонстрацию за запущенный публичный сервис. После одобрения инструкция стенда предусматривает один переключатель для использования заранее настроенных Production-ключей.
