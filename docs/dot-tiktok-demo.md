# Задание для Dot — TikTok Sandbox

Подготовь демо будущего кабинета автора Poster на уже развёрнутом стенде. Владелец передаст адрес стенда и путь к приватному файлу входа. Логины кабинета — `author-a` и `author-b`. Каждому нужен отдельный профиль браузера.

1. Открой существующее приложение Poster на TikTok for Developers и переключись в Sandbox. Выбери его тестовую конфигурацию или создай Sandbox внутри этого приложения. Включи Login Kit для Web, Display API и Content Posting API для загрузки во входящие. Сохрани точный Redirect URI из приватной инструкции стенда. Запроси `user.info.basic`, `video.list`, `video.upload`.
2. В настройках Sandbox добавь target users. На шагах входа, MFA и согласия передай управление владельцу соответствующего аккаунта. Каждый подключает свой TikTok. Применяй изменения только в Sandbox.
3. В приватном терминале на сервере открой `sudoedit /srv/poster-tiktok-demo/shared/.env` и заполни только `TIKTOK_DEMO_SANDBOX_KEY` и `TIKTOK_DEMO_SANDBOX_SECRET` данными выбранной Sandbox. Сохрани права файла. На этом стенде config cache отключён, изменения вступают в силу со следующего запроса. Если у тебя только браузер, попроси оператора сервера заполнить эти два поля через секретный канал. Не выводи значения в чат, логи или запись экрана.
4. Открой указанный адрес кабинета, войди как первый тестовый автор и нажми «Подключить TikTok». Покажи владельцу экран согласия. После возврата проверь имя профиля, ответ списка роликов и доступные метрики. Для пустого аккаунта ожидается «Публичных роликов пока нет». Ошибку API запиши как ошибку. Повтори с другим автором в другом профиле браузера. Проверь, что переход первого автора по адресу второго возвращает 404.
5. Оставь `TIKTOK_DEMO_UPLOAD=false`. Для демонстрации достаточно показать кнопку и объяснить завершение публикации во входящих TikTok. Отправку файла, публикацию и отправку на модерацию владелец согласует отдельно. Сценарий записи и удаление описаны в [инструкции кабинета](tiktok-demo.md).
6. Верни владельцу короткий отчёт по каждому автору: согласие получено или ожидается, профиль получен или нет, список пуст / показаны ролики / ошибка. Отметь отдельно, что передача файла проверялась только автотестом. Исключи из отчёта секреты, ссылки обратного вызова с параметрами и идентификаторы аккаунтов.
