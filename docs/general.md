# Правила разработки Poster

Перед изменениями проверьте ветку, индекс и рабочее дерево. Соглашения по структуре кода собраны в [архитектуре](architecture.md), требования к оформлению — в [стиле PHP](code-style.md).

Изменения схемы оформляйте миграциями. Проверьте ограничения и индексы на существующих данных. Для переноса данных определите порядок применения, проверки результата и восстановления из резервной копии.

Проверяйте доступ к записи при чтении и перед выполнением фоновой операции. Ключи интеграций храните в конфигурации окружения. В журнал записывайте идентификатор операции и причину сбоя. [Авторизация](authorization.md) · [Журналирование](activity-log.md)

Для изменений поведения запускайте [тесты](testing.md), для изменений HTTP-контрактов сверяйте [документацию API](apidoc.md). Команды локальной проверки приведены в [README](../README.md), порядок выпуска — в [инструкции по развёртыванию](deployment.md).
