# Граф кода Poster

[Graphify](https://github.com/graphify-labs/graphify) строит локальный граф символов
и связей PHP, Vue/TypeScript и остального поддерживаемого исходного кода.
Он помогает найти зависимости, callers и соседние классы перед чтением реализации.
Карта ответственности и сценариев — в [architecture.md](architecture.md#архитектура-poster).

## Установка и генерация

CLI выполняется на хосте, отдельно от Composer/npm и Docker runtime приложения.
Проверенная версия — `graphifyy==0.9.94` (имя команды — `graphify`). Если CLI
уже доступен, повторная установка не нужна. Для новой среды с Python 3.10+ и pipx:

```sh
pipx install 'graphifyy==0.9.94'
graphify --version
make graph
```

`make graph` выполняет `graphify extract . --code-only --max-workers 2`, затем
`graphify cluster-only . --no-label`. Используется локальный AST-разбор без
LLM-запросов и API-ключей. Документы, изображения и PDF семантически не индексируются;
подписи сообществ остаются техническими. Существующий установленный CLI можно
указать через `make graph GRAPHIFY=/path/to/graphify`.

Результаты находятся в `graphify-out/`:

| Файл | Назначение |
|---|---|
| `graph.json` | Машиночитаемые символы, связи и ссылки на исходные строки |
| `graph.html` | Интерактивный поиск, фильтры и просмотр связей в браузере |
| `GRAPH_REPORT.md` | Сводка сообществ и наиболее связанных узлов |

Это локальные генерируемые артефакты, исключённые из Git. В новом checkout их
нужно создать командой `make graph`. Для обновления после правок — `make graph-update`:
тот же pipeline повторно сканирует изменившиеся файлы и пересоздаёт отчёт/HTML.
После изменения списка исключений также обновляйте граф. Только HTML можно
пересоздать через `make graph-html`.

## Использование агентом

Команды выполняются из корня Poster и по умолчанию читают `graphify-out/graph.json`:

```sh
graphify explain 'MakeShortAction'
graphify query 'video generation' --seed 'app/Actions/SaveVideoAction.php' --budget 1500
graphify affected 'app/Models/Prompt.php' --depth 2
graphify god-nodes --top 10
```

Если имя неоднозначно, CLI возвращает кандидатов: повторите запрос с точным ID
из результата. Для визуального изучения откройте `graphify-out/graph.html`.
Если граф отсутствует или старее правок исходников, сначала выполните
`make graph-update`; сохранённая ревизия HEAD сама по себе не учитывает dirty diff.

Граф — средство навигации. Связи `INFERRED` являются выводами анализатора,
а отсутствие связи не доказывает отсутствие вызова. Проверяйте в исходниках
и тестах динамические зависимости Laravel: `#[Bind]`, контейнер, named routes,
автообнаружение listeners, очереди, Eloquent relations и Media Library.
Vue template bindings и соответствие Inertia-имени PHP-контроллера файлу страницы
также требуют проверки. Ни полнота графа, ни число связей не доказывают
безопасность удаления класса или корректность runtime.

## Состав индекса

Исключения определяет корневой [.graphifyignore](../.graphifyignore), дополнительно
учитывается `.gitignore`. В граф не входят `.env*`, credentials-файлы, приватное
`storage/`, логи, дампы БД, `vendor/`, `node_modules/`, сборки, кеши, публичные
assets и конфигурация инструментов агентов. Тесты и миграции входят в индекс:
сверяйте `source_file`, чтобы не принять fixture или assertion за runtime-вызов.

Сборка графа не запускает Artisan, генераторы, публикацию, миграции или уведомления.
Не добавляйте приватные данные в индекс и не включайте семантическую обработку
внешними моделями ради обычного обновления графа кода.
